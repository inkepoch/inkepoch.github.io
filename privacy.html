MiaMail

プライバシーポリシー

制定日: 2026年10月14日

MiaMail（以下「本アプリ」）は、開発者本人が自分のMacで使うための個人用メールクライアントです。本ポリシーは、本アプリがGoogleユーザーデータをどのように扱うかを説明します。

取得するデータ

本アプリはGoogle OAuthで https://www.googleapis.com/auth/gmail.modify の権限を求め、Gmail APIから次のデータを取得します。

  • Googleアカウントのメールアドレス
  • 受信トレイのメッセージの差出人、件名、日付、抜粋、ラベル
  • 利用者がメールを開いたときの本文と添付ファイル名

利用目的

取得したデータは、受信箱の一覧表示、新着通知、本文の表示、既読・未読の切り替え、アーカイブ、ゴミ箱への移動、利用者が作成したメールの送信のためだけに使います。広告、プロファイリング、機械学習モデルの学習には使いません。

保存

  • メールの一覧と本文はアプリの実行中にメモリ上で保持するだけで、ディスクには保存しません。
  • OAuthのリフレッシュトークンとクライアント情報は、利用者のMacのキーチェーンに保存します。アクセストークンはメモリ上でのみ保持します。
  • 登録したアカウントのメールアドレスは、利用者のMac内の設定ファイルに保存します。
  • 新着通知として、差出人と件名がmacOSの通知センターに表示されます。

共有と送信先

本アプリは、GoogleのAPI（gmail.googleapis.com、oauth2.googleapis.com）とのみ通信します。開発者が運営するサーバーはなく、Googleユーザーデータを開発者や第三者へ送信、販売、共有することはありません。

Google API Services User Data Policy への準拠

本アプリによるGoogle APIから取得した情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use要件を含む）に従います。

データの削除とアクセスの取り消し

  • 本アプリの設定からアカウントを削除すると、キーチェーンに保存した認証情報も削除されます。
  • Googleアカウントの「サードパーティ製のアプリとサービス」から、本アプリへのアクセスをいつでも取り消せます。
  • Gmail上のメールは、本アプリでアカウントを削除しても削除されません。

改定

本ポリシーを変更する場合は、このページを更新し、制定日の欄に改定日を記載します。
